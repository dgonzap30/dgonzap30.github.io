Seven practices, each derived from something that runs.

Seven practices for running an agent fleet, each derived from a working artifact rather than written as advice.

Every page names its own source

01

The operating manual

An agent that has to be briefed by hand every session is a tool. An agent that reads the rules for wherever it happens to be working is a colleague. The difference is a file, placed where the work is.

Artifact~/.claude/CLAUDE.md and per-project CLAUDE.md / AGENTS.md

02

Worktrees

Agents and people edit the same repositories at the same time. A single checkout makes that a queue; a worktree per branch makes it parallel, and a fixed location makes it findable.

Artifact~/.claude/rules/project-inventory.md

03

The fleet

Running several agent sessions at once is easy. Finding the one you want twenty minutes later is the actual problem, and it is a naming problem before it is a tooling problem.

Artifact~/.local/bin/work

04

The session catalog

Agent sessions produce the most detailed record of how work actually happened, and then that record becomes unreadable — thousands of transcripts, no index, no way to ask what was decided and why.

Artifact~/dev/lodestar/tools/session-catalog

05

Verification

An agent asked whether its work is correct will tell you that it is. Not dishonestly — it is the same context, reasoning the same way, reaching the same conclusion. Independent review has to actually be independent.

Artifact~/.claude/agents/verify-depth.md and ~/.claude/workflows/fan-out-verify.js

06

Eval-gated skills

Agent instructions are edited by feel. Someone reads a bad output, rewrites a paragraph, and the change ships because it sounds better. Nobody measures whether it helped, and nobody notices when it hurt.

Artifact~/dev/_tools/skillopt

07

The attention ledger

A portfolio of projects generates a comforting amount of activity. Counting it naively produces a number that feels like progress, and the main thing that number measures is how much of the work was done by a robot on a timer.

Artifact~/dev/METRICS.md
