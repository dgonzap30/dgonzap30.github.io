The series →

Seven practices for running a fleet of AI coding agents, each taken from something that runs.

  1. 01The operating manualHow a layered set of CLAUDE.md and AGENTS.md files gives every agent the rules for the directory it is standing in.
  2. 02WorktreesWhy every branch gets its own working tree, where they are allowed to live, and the two-line helper that enforces it.
  3. 03The fleetHow a 132-line shell script keeps parallel agent sessions findable instead of scattered across terminal tabs.
  4. 04The session catalogA local Swift daemon that indexes agent transcripts into a read-only catalog and serves six search tools back to the agents that wrote them.
  5. 05VerificationAn adversarial review layer that attacks findings on four fixed lenses and fails closed when it cannot reach a verdict.
  6. 06Eval-gated skillsA loop that edits an agent skill, measures the change against a held-out eval set, and refuses to promote it without a statistical margin and an independent verdict.
  7. 07The attention ledgerOne file defines every metric, three reporters read it, and the hardest work was removing the automation from its own numbers.
