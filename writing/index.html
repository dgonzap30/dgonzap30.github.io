The series

Seven practices for running a fleet of AI coding agents, each taken from something that runs.

  • The operating manualPart 1How a layered set of CLAUDE.md and AGENTS.md files gives every agent the rules for the directory it is standing in.
  • WorktreesPart 2Why every branch gets its own working tree, where they are allowed to live, and the two-line helper that enforces it.
  • The fleetPart 3How a 132-line shell script keeps parallel agent sessions findable instead of scattered across terminal tabs.
  • The session catalogPart 4A local Swift daemon that indexes agent transcripts into a read-only catalog and serves six search tools back to the agents that wrote them.
  • VerificationPart 5An adversarial review layer that attacks findings on four fixed lenses and fails closed when it cannot reach a verdict.
  • Eval-gated skillsPart 6A loop that edits an agent skill, measures the change against a held-out eval set, and refuses to promote it without a statistical margin and an independent verdict.
  • The attention ledgerPart 7One file defines every metric, three reporters read it, and the hardest work was removing the automation from its own numbers.
